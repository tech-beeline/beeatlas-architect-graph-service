# Project Summary

## Overview of Technologies Used
The project is primarily developed using **Java** as the programming language. It utilizes the **Spring Framework** for building the application, and **Maven** as the build automation tool. The project is structured to follow a clean architecture approach, allowing for better maintainability and scalability.

### Main Libraries and Frameworks:
- **Spring Boot**: For building the application and managing dependencies.
- **Spring Data Neo4j**: For interacting with Neo4j databases.
- **Spring Web**: For creating RESTful web services.
- **Spring Security**: For authentication and authorization.
- **Swagger**: For API documentation.
- **JUnit**: For unit testing.

## Purpose of the Project
The purpose of the project is to provide a robust architecture for managing and visualizing graph-based data using Neo4j. It aims to facilitate operations such as authentication, data retrieval, and diagram generation, making it easier to manage complex relationships within the data.
